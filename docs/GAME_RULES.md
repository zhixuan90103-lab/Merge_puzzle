## 0. 一句话（主线）

**同色合成做大体 → 用合后的体积把杂色推出盘 → 盘上只剩一种颜色并合出满屏 64 → 清盘进入下一关。**

---

## 1. 设计意图

| 意图 | 说明 | 状态 |
|------|------|------|
| 主循环 | 合成 + **推净杂色** + **单色满盘** + 下一关 | 已定 |
| 空间 | **越合越满**（N 占 N；合不腾空） | 已定 |
| 色 = 阵营 | **同色**才合；异色是障碍 | 已定 |
| 流放 | 推光某色后，**本波出块不再刷该色** | 已定 |
| 合后形 | **由摆放决定**（A∪B 实心矩形），不锁死下一级外形 | 已定 |
| 不做 | 消行、限时、异色合、同体积互推、搬家旋转、>5 色 | 已定 |

---

## 2. 棋盘与块

| 项 | 内容 | 状态 |
|----|------|------|
| 棋盘 | 8×8 | 已定 |
| 块 | **色 + 体积(value) + 轴对齐矩形** | 已定 |
| 体积 | value = N 则占 **N 格** | 已定 |
| 色 | 合并不变；半出盘裁切 **色不变** | 已定 |

数值链：`1 → 2 → 4 → 8 → 16 → 32 → 64`（64 = 满盘 8×8）。

---

## 3. 操作（唯一：拖）

| 松手 | 结果 | 状态 |
|------|------|------|
| 投影脚印 **全空** | **搬家** | 已定 |
| 与 **同色同体积** **重叠≥1** 且有合法合后形 T* | **合并** | 已定 |
| **原位** | 放回，**不合** | 已定 |
| 异色 / 朝向不合 / 硬挡 / 无 T* | 禁止，弹回 | 已定 |

### 预览（拖合一体）

| 层 | 含义 |
|----|------|
| **G 投影** | 贴格落点：绿可放 / 蓝可合 / 红非法 |
| **F 跟手** | 连续体；生长意图 |
| **T* 紫虚线** | 合后外形预告；松手只认预览帧 |

实现：`dropResolve.ts` · `view.ts` · `game.dropAt`。

---

## 4. 合并

| 项 | 规则 | 状态 |
|----|------|------|
| 条件 | **同色** + **同 value** + **朝向相容**（横合横、竖合竖；正方形可配同色同值） | 已定 |
| 结果值 | `2 × value`；**色不变** | 已定 |
| 锚点 | B 同 id **生长**；A 被吸收 | 已定 |
| 合后形状 | 任意 **w×h = 2V** 且在盘内的矩形；**优先玩家摆出的 A∪B 实心外包** | 已定 |
| 例 | 两竖 2 首尾叠 → 1×4；两 8 贴长边 → 长条 16；贴成方 → 4×4 | 已定 |
| 净占格 | 两 V 合为 2V，占格不减 | 已定 |

生长方向：跟手相对 B；真空槽可双侧；须在盘内。  
执行：`findMergeShape` → `tryMerge(..., forcedTarget: T*)`。

---

## 5. 推挤（清杂色）

| 规则 | 状态 |
|------|------|
| 比较对象 = **合后 2V** | 已定 |
| 障碍 **&lt; 2V** → 可推；**≥ 2V（含同体积）** → 挡死，整合失败 | 已定 |
| 不看色（异色也可被更大体积推） | 已定 |
| 沿生长方向；可连锁；盘内可推 | 已定 |
| 动画中整块滑、不改号；**全出盘** → 移除 | 已定 |
| **半出盘** → 结算后裁切，value = 剩格，**色不变** | 已定 |

---

## 6. 关卡与色种

| 关 | 开局色种 | 备注 |
|----|----------|------|
| 1 | **2** | 主色大料 + **一枚**副色 4（教学：要推开才能满屏） |
| 2 | 2 | 副色出块少 |
| 3 | 2 | 副色出块增多 |
| 4–5 | **3** | 新色权重低 |
| 6–7 | 4 | 最新色最低 |
| 8+ | **5** | 上限 |

实现：`progress.unlockedColorsForWave` · `deal.dealOpening`。

### 过关

1. 盘上出现 **value = 64**（满 8×8）  
2. 消除 → 全盘空  
3. **立刻重摆**下一关（色种按上表）  

禁止在「仅有满盘 64、未清」时判死局。

---

## 7. 流放与出块

| 规则 | 状态 |
|------|------|
| 出块 **仅合并成功后**（非 64 清盘时） | 已定 |
| 只刷 **当前盘上仍存在的色**；推光则退池 | 已定 |
| 盘上仅 1 色 → 只刷该色 | 已定 |
| 优先补可合对；防「只合一次就死」；有空尽量有料 | 已定 |
| 体积池随关卡/盘面变化（大块关、碎块关） | 暂定数值 |

实现：`spawn.ts` · `progress.boardActiveColorWeights`。

---

## 8. 失败

**不能搬家且不能合法合并** → 死局 → 重开。  
实现：`isPlayable`（快）/ `isDeadlock`（终局确认）。
