## 1. 一句话

在 **8×8** 上拖块：空位搬家；**同色 + 同体积 + 朝向相容** 可合并；**异色不合**，推只比体积。开局 **1 色**；某色合成 **满屏 64**（独块）→ 消除并 **重制关卡**；重制时若未满 **5 色**则 **多解锁 1 色**。无法搬合则失败。

---

## 2. 设计意图

| 意图 | 说明 | 状态 |
|------|------|------|
| 空间哲学 | **越合越满**；满屏才减压 | 已定 |
| 主循环 | **多色开局 → 选定主色 → 推走异色 → 单色冲 64 → 清盘加色** | 已定 |
| 合并条件 | **同色** + 同值 + 朝向 | 已定 |
| 推 | 体积 **&lt; 合后 2V** 可推；同体积不可推；不看色 | 已定 |
| **流放循环** | 盘上 **推光某色后，出块不再刷该色**；剩一色则只刷该色 | 已定 |
| 合并占格 | N 占 N；两同值合后净占格不减 | 已定 |
| 不做 | 消行；异色合；>5 色 | 已定 |

说明：64 占满 8×8，满屏时盘上只有该块；结算 = 消 64 + 按已解锁色种重发块。

## 4. 操作

### 4.1 唯一手势：拖

| 松手情况 | 结果 | 状态 |
|----------|------|------|
| 投影脚印 **全空** | **搬家** | 已定 |
| 投影与同数 **重叠≥1** 且存在合法生长形 T* | **合并** | 已定 |
| 投影在 **拿起原位** | **放回**（取消意图，不合） | 已定 |
| 不同数 / 硬挡 / 无 T* | **禁止**，弹回 | 已定 |

| **跟手 F** | 连续跟指（可偏）；**生长意图** | 已定 |

## 5. 合并规则

### 5.1 数值

| 项 | 内容 | 状态 |
|----|------|------|
| 条件 | **同色** + 相同数字 + **朝向相容**（横↔横、竖↔竖；方块可与同值同色任意朝向） | 已定 |
| 结果值 | `newValue = 2 × value`；**色不变** | 已定 |
| 成功后 | 移除 A；**B 同 id 生长** 为 `newValue` 与 T* 形（不删 B 重生） | 已定 |

### 5.2 占格

| 项 | 内容 | 状态 |
|----|------|------|
| 体积 | 数值 **N 占 N 格** | 已定 |
| 推论 | 两块值 V 合并为 2V 后，净占格不变（2V→2V）；**空位不靠合并增加** | 已定 |

### 5.3 形状

| 值 | 占格 | 形状 | 状态 |
|----|------|------|------|
| 1 | 1 | 1×1 | 已定 |
| 2 | 2 | 1×2 或 2×1（由拖势） | 已定 |
| 4 | 4 | **2×2 正方形** | 已定 |
| 8 | 8 | **两个 4**：2×4 或 4×2 | 已定 |
| 16 | 16 | **两个 8** 再横贴或竖贴 | 已定 |
| 32 | 32 | 两个 16 递推 | 暂定枚举 |
| 64 | 64 | **8×8 全盘** | 已定 |

- 轴对齐矩形。  
- v1：**搬家不旋转**；朝向主要在 **合并生成新形状** 时确定。

### 5.4 长大方向（已定 · v0.4）

**分工：投影定能否合；跟手 F 相对 B 定怎么长；T* 预告并强制执行。**

| 规则 | 状态 |
|------|------|
| 意图来源 | **跟手 F** 相对 B（中心偏置 + 伸出）；碎块布局不主导方向 | 已定 |
| 单侧 | 偏哪侧 → 向该侧扩 | 已定 |
| 双侧 | **真·空槽**可填满时（如横 4×竖 2 中心 4）→ 该轴两侧各蔓延 | 已定 |
| 正中 | 末段/进入方向反推进入侧 | 已定 |
| 朝向锁 | **先于** 几何 | 已定 |
| 出界 | T* 与生长中间态须在 8×8 内；意图非法 → 不合（不静默改向） | 已定 |
| 执行 | `findMergeShape` → `tryMerge(..., forcedTarget: T*)` | 已定 |

### 5.5 占位结算顺序（已定）

```
1. 确认：同数 + 朝向相容 + 脚印重叠达阈值
2. 记录 B 锚、生长方向趋势、投影 ghost、双方旧值 V
3. 从盘上移除 A（旧格变空）
4. 以 B 为锚，按趋势生成值为 2V 的单边生长目标矩形（须在盘内）
5. 新形状允许覆盖 A 刚腾出的格子
6. 逐格生长：每格与「大推小」同拍；整条推挤链同时位移
7. 任一步失败 → 恢复盘面，A 弹回（或降级搬家）
8. 成功 → 写入 B 新值与新形状；半出盘块结算裁切
9. 若出现 64 → 清空并重摆（见 §6），再继续
10. 出新块（见 §7）
11. 检查失败（见 §8）
```

### 5.6 大推小（已定 · v0.3）

| 规则 | 状态 |
|------|------|
| 比较对象 | 用 **合并后的新值** `2V` 与障碍块的值比较 | 已定 |
| 可推条件 | 障碍值 **&lt; 2V** 可推；**同体积不可互推** | 已定 |
| 障碍 ≥ 2V | 不可推 → **整次合并失败并弹回** | 已定 |
| 推出方向 | 沿本次生长/扩展方向 | 已定 |
| 连锁 | 外侧先；可连锁顶更外侧的更小块；**整条链** 同拍记录与动画 | 已定 |
| 推出动画 | **整块** 平移；过程中 **不** 改数值/颜色/尺寸 | 已定 |
| 被推观感 | **不浮起**（不高 z、不大阴影）；贴盘被顶 | 已定 |
| 完全出盘 | 整块移出 8×8 后 **移除** | 已定 |
| 半出盘结算 | 合并 **全部步骤结束后** 仍半在盘内 → 裁切盘内矩形，`value = 剩余格数` | 已定 |
| 逻辑步进 | 每步 1 格；表现层连续插值（非跳格感） | 已定 |
| 合失败 | 推不动（墙/更大块）→ 整单回滚 | 已定 |
| 防软锁 | 合并多方案时 **优先选推挤后仍可行动** 的布局；随后出块优先 **解除死局**（如补竖 2） | 已定（原型） |

## 6. 64 与续局

| 项 | 内容 | 状态 |
|----|------|------|
| 触发 | 盘上成功存在值为 **64** 的块 | 已定 |
| 效果 | 移除该 64；在 8×8+满占规则下即 **全盘空** | 已定 |
| 续局 | 系统 **立刻自动再摆一批块** | 已定 |
| 开局摆盘 vs 64 后重摆 | **暂先同一套规则**；以后可拆 | 暂定 |
| 一局内 64 次数 | 模式/关卡参数，非核心机制分支 | 已定 |

**结算顺序（硬性）**

1. 合并成功  
2. 若产生 64 → **先清空 + 重摆**  
3. 再判定失败  

禁止在「仅存在满盘 64、尚未清空」时按死局判负。

## 7. 出新块

| 项 | 内容 | 状态 |
|----|------|------|
| 到 64 前是否出块 | **会**（中途向盘上加块，强化越来越满） | 已定 |
| 数字种类 | **1 / 2横 / 2竖 / 4**；权重随盘面最高值分阶段 | 已定（v0.4） |
| 前期 (max&lt;8) | 1 较少；2 为主；4 可观 | 已定 |
| 中期 (max≥8) | 1 更少；2/4 并重 | 已定 |
| 后期 (max≥16) | 几乎不出 1；2/4 为主（便于推中档块） | 已定 |
| 公平原则 | 出块后须 `isPlayable`；禁止一出即软锁 | 已定原则 |
| 触发时机 | **仅合并成功后** | 暂定（原型） |
| 开局摆盘 | **底边整齐**、少碎块；上半留空（`dealOpening`） | 已定（v0.4） |
| 出现表现 | 新生块短动画 | 暂定（原型） |

与空间哲学的关系：合并不增加空位，出块增加占用 → 密度上升 → 推动冲刺 64 清空。

## 8. 失败

| 项 | 内容 | 状态 |
|----|------|------|
| 条件 | 当前 **无任何合法合并**，且 **无任何合法搬家** | 已定 |
| 合法合并 | 存在一对同数且按 §5 至少一种拖势/落位可成功完成（含推） | 已定 |
| 合法搬家 | 存在一块与一组合法空脚印，使整块可平移放入 | 已定 |
| 死亡归因 | 主要来自玩家操作与局面演化；出块不得秒杀 | 已定原则 |

## 9. 主循环（逻辑）

```
玩家拖起一块 A（格点 hit-test）
  ├─ 拖动中持续 proposeDrop（绿/蓝/红投影）
  ├─ 松手提交 proposal.ghost
  │     ├─ 蓝·可合 → §5 合并
  │     │     成功且值为 64 → §6 清空并重摆
  │     │     成功 → §7 出新块
  │     │     失败可降级搬家或弹回
  │     │     → §8 检查失败
  │     ├─ 绿·可搬 → 搬家 → §8
  │     └─ 红·非法 → 弹回
```

## 11. 状态总表

### 已定

- 拖合一体：G 落点 / F 意图 / T* 预告；松手认预览  
- 空=搬；重叠≥1+同数+朝向=合；边邻只搬；原位放回

- 失败=不能合且不能搬；不做行/列消除  

### 暂定

- 棋盘 8×8  
- 开局与 64 后同套  
- 16+ 形枚举细节  

### 未定
