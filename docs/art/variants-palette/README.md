## 生产用 token 草案（选定后精修 hex）

选定 `Pn` 后写入 `ART_DIRECTION` 的：

- `--stage-0/1` 舞台  
- `--tray` 托盘  
- `--piece-0…4` 五色  
- `--btn-primary`  
- `--ink` / `--ink-muted`  
- 反馈：可合/非法/T\* 从主色派生，本轮不单独立项  

下一维度建议顺序：② 明度/对比 → ③ 材质（磨砂厚度）→ ④ 舞台装饰量 → ⑤ UI 重量。
