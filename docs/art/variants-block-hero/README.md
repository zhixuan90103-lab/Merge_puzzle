# 维度 · 块特征 + 主体突出

## 目标

- 块 = **玩法主角**（视觉权重 > 舞台/UI）
- **略有特征**，但不回贴图/数字
- 仍轻松浅色

## 特征语言（推荐）

| 层 | 做法 | 不做 |
|----|------|------|
| 体积 | 可见侧厚 / 顶面略亮 | 全平色块 |
| 边缘 | 1px 柔 rim / 内阴影 | 硬黑描边、彩虹描边 |
| 落地 | 接触影，托盘略凹 | 块与盘糊成一片 |
| 材质 | 磨砂橡胶漫反射 | 糖膜高光、贴纸图案 |
| 信息 | 仅色 + 面积 | 默认数字/图标 |
| 层级 | 舞台最淡，UI 次，**块最实** | 背景抢戏 |

## 实现提示（DOM）

```css
.piece {
  border-radius: 14px;
  background: linear-gradient(160deg, tint 0%, base 45%, shade 100%);
  box-shadow:
    inset 0 2px 0 rgba(255,255,255,.4),
    inset 0 -2px 3px rgba(0,0,0,.06),
    0 6px 14px rgba(40,50,60,.14);
  /* 抬起时 z-index + shadow 加深 */
}
#board-root {
  /* 托盘比块更浅、更平 */
  box-shadow: inset 0 2px 8px rgba(0,0,0,.04);
}
```
