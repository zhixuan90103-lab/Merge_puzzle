## 0. 一句话

**逻辑锁 B，块跟手；能合则画一体皮 + 合后形半透明本体；被推块按盘面相对位置挪开；松手：盘内钉死变实，出盘沿推力滑出淡掉。预览与结算同一份 T\*。**

---

## 1. 本轮改了什么

| 主题 | 设计 |
|------|------|
| 位置吸附 | 表现层拉力 = 0；逻辑仍 LOCKED + ghost 弱拉，只服务结算 |
| 融合皮 | SVG goo 最高层；不藏、不抽原块；字/高光在皮上 |
| 高光/数字 | 融合时只留拿起块高光；两数滑向中间加成，然后只留合后数 |
| 贴格蓝框 | 隐藏（逻辑提案仍在） |
| 非法回位 | 飞回原格 + 轻闪；同一块可反复闪 |
| 进锁 | 连续指位重叠；优先认正在压着的可合块；大块进锁距离随尺寸 |
| T* | 半透明本体色，50%；从 B 长出；一种长法钉死；多种要过磁滞+100ms |
| 锁着 | 紫框不消失；松手按钉住的 T* 合成 |
| 推挤预览 | 原块真的挪；与 T* 同时长、同一条 cubic、同一段时长 |
| 出盘预览 | 整组按盘面相对位置平移出沿；还在盘上的保持格序 |
| 松手 | 盘内：透明度回 1、钉在落点，不重推。出盘：继续滑出并淡出 |
| 取消 | ~48ms 收回，不跟生长抢 |

## 2. 问题 / BUG → 设计

| # | 现象 | 根因 | 设计 |
|---|------|------|------|
| Q1 | 吸附只有感觉、两块不像一体 | 只弱拉坐标，无融合皮 | 逻辑锁 ≠ 焊死；皮是第三层，跟连续指位 |
| Q2 | 皮比块大、圆角更圆 | goo 糊 + 厚度一起糊 | 只糊顶面；源 rx 小于 15；对比收紧 |
| Q3 | 藏原块后细节全丢 | 替换成皮 | **永不藏原块** |
| Q4 | 厚度没了 | 皮盖住厚度，或抽层丢 CSS 变量 | 皮在最高；厚度留在块上 |
| Q5 | 数字/高光被皮盖住 | 皮 z 最高 | 装饰层在皮上：一高光 + 加成数字 |
| Q6 | 路过同色才锁 / 叠一半不锁 | 贴格中心距 1.15；大块中心太远 | **连续重叠 ≥ 0.22** 或按尺寸加长进锁 |
| Q7 | 锁错块 | 认中心最近，不认正在压的 | 有重叠优先重叠块 |
| Q8 | 有皮无紫框 | 一帧非法就清 T* | 锁着保留上一份可行 T*；松手认它 |
| Q9 | 块在右、框朝上 | 空地分压过位置；落点反号 | 多种长法：**伸出边优先**；空地只作首次/过门槛后决胜 |
| Q10 | 紫框闪 | 多种长法每帧换 T* | 钉住；换向须多伸出 0.4 格且稳住 100ms |
| Q11 | 推预览看不出 | 只画分身 | **原块挪开** + 降透明 |
| Q12 | 预览后块不回、留空档 | 拖时不重绘；换向丢掉旧 id | 离开预览集的块立刻种回 rest |
| Q13 | 同排块堆叠 / 靠边看不见 | 所有出盘块收成一条链；出界按整块宽度算透明 | **整组刚体平移**保盘面相对位置；还在盘上不按出界淡 |
| Q14 | 同排两 4，靠外的没了 | 按列排队把后排送出屏 | 同 Q13：平移不是重排 |
| Q15 | 框快块慢 | 框 cubic、块 quad；起算不同步 | 同时起、同时长、同一条 cubic |
| Q16 | 松手先回原位再推 | 盘内块离开预览集，时间轴从 rest 开推 | 盘内块 **pin 在 dest** 直到结算完 |
| Q17 | 钉死合后块导致不见生长、数字不变 | 把 B 也钉在 T* 上并关掉 motion | **禁止钉 B**；生长与数字走时间轴 |
| Q18 | 出盘确认像再甩一次盘内块 | 所有预览块都 fly-out | **仅出盘** fly-out；盘内只回不透明 |

## 3. 运行时分层（锁住能合）

```
高  数字加成 / 拿起块高光
    Goo 皮（接缝）
    拖动块 A（跟手）
    盘面块（被推的按预览 dest 画）
    T* 半透明本体（50%，从 B 长出）
低  棋盘格
```

禁止：藏 A/B、抽厚度、用贴格蓝框当主反馈。

---

## 4. T* 钉住与换向

```
LOCKED + 首次可行 T* → 钉住并显示（从 B 长出）
唯一生长方式     → 整段锁定期不换
多种生长方式     → 默认保持
                    新方向伸出 ≥ 旧方向 + 0.4 格
                    且连续 ≥ 100ms
                    → 换成新 T*，再从 B 长一次
UNLOCKED         → 清框；被推块 48ms 收回
pointerup        → 只认钉住的 T*（与最后一帧预览一致）
```

锁着时某一帧 `proposeDrop` 非法：**不摘框**，提案改写成钉住的 merge。

---

## 5. 推挤预览

1. 用钉住的 T* 跑 `computePushPreview`（内部 `tryMerge`），与松手同一计划。  
2. **原块**从 rest 插到 dest；与 T* **同时、同 cubic、时长 = 生长格数 × 95ms**。  
3. dest 布局：出盘子集相对 rest **刚体平移**，刚好出沿 + 0.35 格。盘内块 dest 用计划格，不重排。  
4. 透明度：还在盘上 ≈ 0.8；完全出盘按内侧离沿变淡，预览最低 ≈ 0.38。  
5. 铁门：计划里没有的块不动。  
6. 换 T*：不在新集合里的 id **立刻**种回 rest。

## 6. 松手确认

| 块 | 行为 |
|----|------|
| 盘内被推 | dest 钉住，透明度 → 1；时间轴不得再从 rest 推它们 |
| 出盘 | 沿推力再滑「生长格数」格，约 78% 路程淡到 0，然后移除 |
| 合后 B | **走时间轴生长**；数字随 value 更新；不要钉死在 T* 上 |
| 拖着的 A | 溶进合后 / 移除 |
| 取消（不合） | 48ms 收回，禁止走确认滑出 |

禁止：倒回 rest 再正式推（盘内）。  
禁止：为消盘面晃动而关掉合后生长或钉死 B。

## 7. 速度

| 常量 | 值 | 用途 |
|------|-----|------|
| `CELL_MS` | 95 | 预览生长、预览推、确认出盘滑出 |
| 取消收回 | 48ms | 仅 UNLOCK / 非法回位 |

## 9. 验收

- [x] 跟手不焊死；锁上出皮  
- [x] 叠一半能锁到正在压的块  
- [x] 一种 T* 不闪；多种要明显挪才换

- [x] 被推原块跟框一起走，取消立刻回、无空档  
- [x] 同排同列相对位置与盘面一致

## Key Decisions

1. **皮 ≠ 换块** — 原块是真源，皮只画接缝。  
2. **T* 钉住 + 磁滞** — 用状态机换向，不用每帧最高分。  
3. **推预览动真块** — 分身读不成「被顶走」。  
4. **刚体平移出沿** — 保盘面顺序；禁止重排成一条链。  
5. **松手分流** — 盘内 pin，出盘 fly；B 仍走时间轴。  
6. **预览与结算一份 T*** — 禁止两套方向。
