## 关键玩家规则（v0.4）

### 落点（投影）

| 投影 | 松手 |
|------|------|
| 全空 | 搬家 |
| 与同数 **重叠≥1** 且有合法 T* | 合并 |
| 不同数 / 硬挡 | 禁止（红） |
| **原位** | 放回，**不**合 |

### 意图（跟手）

- 偏一侧 → 向该侧长  
- 中间真空槽 → 可双侧各蔓延  
- 预览紫虚线 = 合后形；松手不二次改向  

### 推

- 沿生长方向；**盘内可推**（非仅出盘）  
- 比较合成后 **2V**
