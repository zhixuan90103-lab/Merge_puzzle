## 关键玩家规则（v0.6）

1. **合**：同色同数 + 朝向相容 + 重叠≥1；外形跟摆放走。  
2. **推**：合后 2V 推更小块；杂色靠推离盘。  
3. **流放**：盘上没了某色 → 不再刷它；剩一色冲 64。  
4. **过关**：64 满屏 → 清盘下一关。  
5. **失败**：不能搬且不能合。
