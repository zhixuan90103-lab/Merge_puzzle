## 关键玩家规则（v0.8）

1. **合**：同色同数 + 朝向相容 + 重叠≥1；外形跟摆放走；**只能拖合，不能搬家**。  
2. **推**：合后 2V 推更小块；杂色靠推离盘；同体积推不动。  
3. **闭包**：盘始终满（Σ=64）；推空后智能补块；推光某色则本波不再刷该色。  
4. **过关**：单色 **64** 满屏 → 清盘下一关（色种随关增加，最多 5）。  
5. **失败**：没有任何合法合，或**每一步合法合都走进死局**（一步死）。**32+32 合 64 是胜利。**
