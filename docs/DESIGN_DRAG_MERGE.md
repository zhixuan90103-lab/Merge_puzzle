本文把原型迭代中踩过的坑收成**可执行设计**，作为意图与推挤的真源。

---

## 0. 一句话

**大拖选合谁（弱吸附锁定）→ 小滑定往哪长 → 生长边对齐才推；无瞄准时 异色可推 > 空地边，禁止无意义居中双侧。**

---

## 1. 问题 → 设计

| # | 现象 / 诉求 | 根因 | 设计决策 |
|---|-------------|------|----------|
| P1 | 长条只蹭大块，整块被推走不合理 | 只比体积、任意重叠即推 | **面对齐**：生长新边宽 N，迎面墙连续 N 格才推 |
| P2 | 4+4 拼满 8 却推不动 | 禁止多块同面 | **多块可拼墙**（连续无缺口） |
| P3 | 同体积不能推，手感过死 | `value >= 2V` 挡 | **仅 value > 2V 铁门**；同体积可推 |
| P4 | 4 与竖 8 同排被顶却失败 | 不同厚度当成同一前缘平面 | **按前缘平面分层**（活塞层） |
| P5 | 居中叠 4 就左右双侧长 | 整段拖向量 + 双侧默认高分 | **两段式**：锁定后才计方向；默认不居中双侧 |
| P6 | 有空边却往中间撑开 | 双侧 4×4 / 并集形分过高 | **空地单侧边**优先于居中双侧 |
| P7 | 想先选目标再定方向 | 粗细操作混在一段拖里 | **FREE 选 B / LOCKED 定方向** |
| P8 | 吸附过强、强制重合 | ghost 焊死在 B | **弱磁吸**（逻辑锁定 ≠ 强制重叠） |
| P9 | 紫框可合、松手失败 | 预览未跑真实 tryMerge | **T\* 必须 merge 可行** |
| P10 | 人在上方/侧方，紫框仍铺空地；异色方向抢不过空地 | 空地分过高；F 被 enter 二次偏移搞反 | **异色 >> 空地**；F 用真实指位；落点参与瞄准 |

## 2. 操作模型（两段式）

```
pointerdown 抬起 A
    │
    ▼
FREE ──────── 大拖：找可合 B
    │ 进入吸附区（中心距 < ENTER 或重叠≥1）
    ▼
LOCKED ────── 逻辑锁定 B；弱拉 ghost；小滑 = 方向
    │ 拖出脱离区（中心距 > EXIT 且无重叠）→ 回 FREE，可换 B
    ▼
pointerup → 只认最后一帧提案
    LOCKED 提交时 A 逻辑落在 B 上再 tryMerge（保证接触）
```

### 2.1 参数

| 常量 | 值 | 含义 |
|------|-----|------|
| `SNAP_ENTER_DIST` | 1.15 格 | 进入 LOCKED |
| `SNAP_EXIT_DIST` | 1.65 格 | 回 FREE（磁滞） |
| `AIM_DEADZONE` | 0.25 格 | 更短不算瞄准 |
| `AIM_COMMIT` | 0.40 格 | 达此 `playerAim=true` |
| `SOFT_PULL_LOGIC` | ~0.32 | 提案 ghost 弱拉向 B |
| `SOFT_PULL_VISUAL` | ~0.22 | 拖动块视觉弱拉 |

方向采样：

1. **吸住后的滑动**（相对进入 LOCKED 时指位）  
2. **手指在 B 上的落点**（相对 B 中心：靠上/下/左/右）  

二者合成；落点偏移 ≥ ~0.32 格即算瞄准。  
不用整段大拖向量。有明确瞄准时，**空地加分削弱**，避免「人在上方、紫框仍往下铺空格」。

### 2.2 方向优先级

```
playerAim（微滑 ≥ COMMIT）
    → 跟瞄准轴；重罚反方向扩张；优先纯单侧
else
    → 异色可推（扩张区内异色且体积 ≤ 2V）
    → 否则空地单侧边
    → 禁止默认「居中双侧」
```

---

## 3. 合后形 T\*

1. 候选：所有面积 = 2V 的盘内矩形，且盖住锚点 B  
2. 体积墙：扩张格上仅允许空 / B / ghost / value≤2V  
3. **可行性**：`tryMerge(..., forcedTarget: T*)` 必须成功  
4. 评分：见 §2.2；明确瞄准时惩罚「反方向 + 双侧居中」

预览与提交同一帧提案（禁止松手重算方向）。

---

## 4. 推挤（生长清障）

比较体积对象 = **合后 2V**。

| 规则 | 说明 |
|------|------|
| 可推 | 障碍 value **≤** 2V，且 **面对齐** |
| 铁门 | value **>** 2V |
| 生长边 | 本步 new cells 形成的连续边，宽 N |
| 迎面墙 | 盖在生长边上的障碍迎面；可多块拼接，须连续、无缺口 |
| 整块对齐 | 每块迎面整条边都在生长面上（半截蹭 → 失败） |
| 连锁 | 按 **前缘平面** 分层匹配下一层墙（厚度不同可同批被顶） |
| 运动 | 整块平移；中途不裁切；全出盘移除；半出结算裁切保色 |

颜色：推挤不看色；**默认选形**时「异色可推」仅用于意图优先级。

## 6. 非目标

- 自由搬家、空地放置  
- 异色合成  
- 推挤按颜色歧视（除默认选形启发）  
- 预览与结算两套方向

## 7. 验收清单

- [ ] 吸住后块不焊死重合，可小范围跟手  
- [ ] 吸住后小滑改变 T\* 方向；不滑走「异色 > 空边」  
- [ ] 有空边时不默认居中双侧  
- [ ] 横条高 2 不能半截推走竖 8 高 4  
- [ ] 4+4 连续墙可被宽 8 的生长边推  
- [ ] 矮 4 + 高竖 8 同排可被向下生长一起顶  
- [ ] 紫框可合 ⇒ 松手 tryMerge 成功（同 T\*）  
- [ ] 无瞄准且一侧有异色可推 ⇒ T\* 朝异色，不先铺对面空地  
- [ ] 手指靠上/靠侧 ⇒ 生长跟落点，不无故铺空  

**关卡债：** `validate:levels` 关 3、5 在新推规则下 clearable=false，需按面对齐重摆（非意图 bug）。
