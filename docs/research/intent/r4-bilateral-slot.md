# R4 — 双侧蔓延与空位槽

## 问题
RQ3, RQ5

## 来源
- 需求例：横 4×竖 2 空区，中心 4，再叠 4 → 左右各 +1 → 4×2  
- Maximal empty rectangle / fit shape（放置问题）  
- Solid union 占位合成

## 可迁移结论
1. 合成目标 = 覆盖 B、面积 2V、∈ 合法形、落在空槽内的矩形 T。  
2. T 相对 B **同轴双侧扩展** ⇒ bilateral（各侧蔓延由空位决定）。  
3. **槽唯一最优** 时可优先于微弱单侧偏置（「填满槽」即意图）。  
4. 单侧意图明确但非法 ≠ 改用对侧；双侧槽是独立合法类。

`findMergeShape(F,B,board)`；U6/U7 为核心验收；打破「永远单边」旧假设。
