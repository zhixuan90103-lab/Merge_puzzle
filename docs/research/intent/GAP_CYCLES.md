### 1.2 计划修订（循环 1）

- 新增 RQ15–RQ18（重叠阈值、aim 点、多目标、槽算法复杂度）  
- Round 6：补漏检索（阈值·aim·多目标·MER）  
- 用例 U11–U13  

### 1.3 补检索结论

| 题 | 结论 |
|----|------|
| 同数可合 | 需求口语是「和自己相同就合成」+ 投影映射；建议 **投影脚印与 B 至少 1 格重叠**（严格于边邻，松于旧 25% 面积，好教）。边邻-only → 搬家倾向，不合。 |
| aim 点 | 行业常见 **contact + 固定上偏移** 作为 aim；G=snap(aim)；F 中心可跟 aim 或 grab+offset。冻结：**aim = finger − (0, offsetY)**，G 与 F 共用 aim 源。 |
| 多目标 | 建筑/列表 DnD：取 **最强命中**；建议 **重叠格数最大，并列中心距 G 最近**。 |
| 空矩形 | 8×8 枚举合法形放置即可 O(shapes×64)；不必上 VLSI 级 MER。候选：对每个 `shape∈Shapes(2V)`、每个 top-left，检测覆盖 B 且除 A∪B 外空。 |
| 竞品 | 棋类：格高亮=落点，棋子跟手=拖项；城建：footprint 绿红；列表：indicator 线 ≠ ghost。 |

## 循环 2

### 2.1 反查缺口（在 C1 之后）

| 缺口 ID | 缺口描述 | 严重度 |
|---------|----------|--------|
| G8 | **A 吸收后** T* 是否必须覆盖 A 的投影格（合时 A 已叠在 B 上） | 高 |
| G9 | **朝向锁**（横只能合横）与意图/槽的顺序：先朝向还是先几何 | 高 |

| G14 | 首轮未写 **性能预算**（每帧 updateDragFrame ms） | 中 |

### 2.2 计划修订（循环 2）

- 新增 RQ19–RQ22  
- Round 7：朝向锁顺序、θ、预告范围、perf  
- 用例 U14–U15、F8  

### 2.3 补检索结论

| 题 | 结论 |
|----|------|
| 覆盖 A | 合时 A 逻辑将移除；T* 须 **覆盖 B 且体积 2V**；宜覆盖 **A 投影与 B 的并集占用意图**（solid union 或槽填充）。中间叠满槽时 T*=槽。 |
| 朝向锁 | **先过滤 canMergeByShape**，再跑槽/单侧。朝向不合 → 直接 blocked（可文案），不进 T*。 |
| θ | 单侧：主轴分量 ≥ 次轴 + ε，且 (protrusion≥0.5 或 exclusive≥1) 则 high；否则 low→走正中/槽。起步 **ε=0.3 格**。 |
| 原位 | 逻辑腾空；观感可 **半透明残影** 在原格（NN/g ghost residual），不占逻辑占用。 |
| T* vs 推 | 预告 **合后锚点形 T\***；推挤动画是后果，可不预告每块推迹（降复杂度）。若推失败则整单失败——与现规则一致。 |
| 性能 | 每帧：snap + 占用查询 O(脚印) + 同数候选 O(n) + 槽枚举 O(\|Shapes\|×64)≤数百次布尔；**禁止** 每帧 tryMerge 全模拟。预算 **&lt;2ms** 设计坐标逻辑。 |

### 3.2 计划修订（循环 3）

- 新增 RQ23–RQ25  
- Round 8：软吸附去留、出界、双/单侧并列、形绑定用例  
- 成功标准补全  

### 3.3 补检索结论

| 题 | 结论 |
|----|------|
| 软吸附 | 新叙事 **投影即结果** → **默认关闭软吸附**；G 是什么就落什么。非法则 blocked/弹回，不偷偷偏一格。若手感过硬可作「仅 place 且距离&lt;0.35 格」可选，默认关。 |
| 出界 | letterbox 外 / 棋盘外：保持最后合法 G 或 blocked；松手弹回。与 AGENTS letterbox 忽略一致。 |
| 动画中 | animating=true **禁止 lift**（已有）；取消仅 cancel 按钮级，不拖。 |
| 双/单并列 | 若槽 bilateral 分 ≥ 单侧分 + margin → 采用双侧并预告双箭头；否则单侧。margin 建议 **等价 0.5 格偏置**。 |
| 形绑定 | U 表扩展：1+1→2、2+2→4、4+4→8 槽、8+8→16 至少各 1 条。 |
| a11y | 后置：VoiceOver 可读 mode；本迭代不做。 |
