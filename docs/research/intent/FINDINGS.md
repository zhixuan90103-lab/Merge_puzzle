## 0. 一体结构（冻结）

```
                    ┌─ 跟手块 F（连续、可半格偏）← 意图 + 舒适
手指 ──► 拖态 ──────┼─ 投影 G（贴格、状态色）    ← 落点合法
                    └─ 合目标 T*（可合时描边/箭头）← 生长结果
松手 ──► 只提交本帧的 (G, T*)，不二次改算
```

| 层 | 职责 | 禁止 |
|----|------|------|
| **投影 G** | 落在哪；空→放，同数→可合，不同→禁止 | 不单独决定生长双侧细节 |
| **跟手 F** | 舒适跟指；相对 B 的偏置表达生长意图 | 不强制格心吸附（否则意图永远正中） |
| **目标形 T*** | 预告合成后外形与单侧/双侧 | 不可见则不许静默改向 |

## 1. Round 1 — 手感：抬起 · 阴影 · 跟手 · 遮挡

### 1.1 可迁移结论

| # | 结论 | 来源倾向 |
|---|------|----------|
| H1 | **抬起要立刻可读**：scale + 阴影 + 略提 z；拖影像宜半透明，便于看见目的地 | Apple HIG：约移动 3pt 即显示拖影像；半透明 |
| H2 | **阴影服务「离板高度」**：轻模糊、小 Y 偏移、中等透明；避免夸张 soft shadow 导致「飘」而看不清对齐 | NN/g、Trello：阴影=已抓起；棋盘游戏宜克制 |
| H3 | **改拖影像仅当增加结果可预测性**（如合时外形变化）；禁止每帧剧烈变形 | Apple HIG |
| H4 | **跟手 1:1 优先**；大块保留 **grab offset**（点哪提哪），避免跳到指心 | 触控 grab offset 实践 |
| H5 | **遮挡**：跟手整体上移一截，保证投影与目标边可见 | finger occlusion 文献 |
| H6 | **拒绝落点必须有反馈**：弹回源或蒸发式 scale+fade，不可静默 | Apple HIG invalid drop |

### 1.2 建议参数区间（设计坐标 390 宽）

| 参数 | 建议起步值 | 说明 |
|------|------------|------|
| lift scale | **1.06–1.12** | 过大挡视线 |
| lift 时长 | **80–120ms** ease-out | |
| 跟手阴影 | `0 8–14px 20–28px rgba(0,0,0,0.35–0.45)` | 克制、稳定 |
| 投影（落点） | 半透明填充 + **2px 实线/虚线描边** | 比大阴影更准 |
| 指上偏移 | **设计 px 12–20**（Y 负向） | 露投影；与 aim 一致 |
| 松手落稳 | **100–150ms** | Apple/行业常见短反馈 |
| 弹回 | **150–220ms** ease-out | |

### 1.3 阴影怎样才「准」（本项目）

1. **双影分工**：跟手块 = 环境阴影（我被拿起）；投影 G = **贴地脚印**（我会落哪）——对齐靠 G 的描边，不靠模糊阴影。  
2. 投影阴影若用，宜 **贴格、低 blur、高不透明描边**，避免软边模糊半格。  
3. 可合时投影/目标形用 **色变 + 外形**，不要只靠阴影加深。  
4. 禁止：跟手巨大阴影 + 无清晰格投影 → 「很高级」但不准。

### 1.4 手感如何服务意图（RQ14）

| 错误 | 正确 |
|------|------|
| 跟手也强制吸附格心 | **F 连续**，才能偏左/偏下 |
| 只有跟手没有贴格投影 | 意图有了，落点糊 |
| 只有投影没有跟手偏置 | 落点清，意图永远正中 |

**冻结句**：`F = 连续跟手（意图）`；`G = 贴格投影（落点）`；分类与合形用 **F 对 B + 空位**，提交用 **G + T\***。

## 2. Round 2 — 落点状态机与反馈

### 2.1 状态（冻结命名）

| mode | 条件 | 投影反馈 | 跟手 |
|------|------|----------|------|
| `place` | 脚印全空 | 绿系半透明 + 实线 | 正常阴影 |
| `merge` | 同数且后续 T* 合法 | 蓝系 + 显示 T* 外形 | 可略强调 |
| `blocked` | 不同数 / 非法 / 放不下 2V | 红系或灰 + 禁止 | 可选轻抖 |

松手：

- `place` → 搬家到 G  
- `merge` → 合，生长按本帧 T*  
- `blocked` → 弹回，不落  

### 2.2 行业一致点

- **抓起反馈**与 **将发生什么预览** 是两段信息（NN/g）  
- 合法/非法 drop zone 要 **进入时就变**，不要松手才知（building placement / SaaS DnD）  
- invalid：**阻止**优于默默改落点（LogRocket 等）

### 2.3 对本项目

与需求一致：**不同数不允许落下**；预览必须在拖动中完成判定。

## 3. Round 3 — 单侧意图几何

### 3.1 推荐主信号：排他格 + 伸出量（protrusion）

相对「纯中心差」更稳：

1. **Exclusive cells**：跟手矩形 F 中 **不属于 B** 的格，质心相对 B 中心 → 侧向向量。  
2. **Protrusion**：F 相对 B 的 left/right/up/down 伸出格数，取最大侧。  
3. 二者冲突时：伸出量 ≥1 格优先；否则用排他质心。

### 3.2 轴与方向

```
adx, ady = |dx|, |dy|
if adx > ady + ε → 横轴，dir = sign(dx)  // 右+ 左-
if ady > adx + ε → 竖轴，dir = sign(dy)  // 下+ 上-
else → 平局：用末段拖动进入侧 或 槽算法（R4）
```

建议 **ε ≈ 0.25–0.4 格**（连续坐标）。

### 3.3 正中（完全盖住）

| 策略 | 建议 |
|------|------|
| 优先 | **进入侧** = 松手前 **80–120ms** 位移的反方向（从下往上拖 → 从下进入 → 向下长） |
| 次选 | 整段拖动反方向（绕路时较差） |
| 不推荐 | 无信号时静默随机侧 |

### 3.4 与手感数据流

```
aim = finger - offsetY
F = center on aim, continuous (no grid snap)
G = round(aim) snapped footprint
side = classify(F, B)   // 不是 classify(G,B)  alone
```

## 4. Round 4 — 双侧槽（核心用例 U6/U7）

### 4.1 形式化

- 值 V 的块 B，合成目标面积 **2V**，合法形集合 `Shapes(2V)`（如 8 → {4×2, 2×4, …}）。  
- **槽** R：轴对齐矩形，全在盘内，R 内除 B（及将被吸收的 A 脚印）外为空，且 `R.size ∈ Shapes(2V)`，且 **R 完全覆盖 B**。

### 4.2 双侧蔓延谓词

对候选 T ∈ 合法且覆盖 B：

- 若 `T` 相对 B 在 **同一轴两侧都有扩展**（如左右都 >0，上下=0）→ **bilateral**  
- 用户例：B 为中间 2×2，T 为 4×2 且左右各扩 1 → 满足  

### 4.3 优先级（建议冻结）

```
1) 若存在槽 T 使 solid-ish 填充「F 意图位 ∪ B」，且 T 为唯一最优（面积/覆盖分）:
     采用 T（可 bilateral）—— 即使 F 略偏一侧，以「填满槽」为玩家意图
2) 否则若 classifySide 置信度 ≥ θ 且 该侧单边目标合法:
     单侧 T
3) 否则:
     mode = blocked（不可合）
```

**关键产品句（与旧「永远单边」不同）**：  
当空位形状 **唯一支持**「中间胀满」时，生长可以是 **双侧各蔓延**，这是意图识别的一部分，不是 bug。

### 4.4 与「不合不改向」

- 单侧意图明确但该侧非法 → **blocked**，不自动改对侧。  
- 双侧槽是 **另一类合法意图**（空间叙事），不是「失败后的静默改向」。

## 5. Round 5 — 一体预览与松手

### 5.1 一帧必显

| 元素 | 有无 |
|------|------|
| 跟手 F + 克制阴影 | 拖动中始终 |
| 投影 G + place/merge/blocked 色 | 始终 |
| T* 外形虚线 | 仅 merge |
| 方向：单侧箭头 / 双侧双箭头 | 仅 merge |
| 原位残影（可选） | lift 后 |

### 5.2 状态机

```
idle → lifting → dragging(update F,G,mode,T*) → 
  release_place | release_merge | release_reject → idle
animating(merge timeline) 期间禁止再 lift
```

### 5.3 时序

| 阶段 | 时长建议 |
|------|----------|
| lift | 80–120ms |
| drag | 跟手无额外 delay |
| 落稳 / 弹回 | 100–150ms / 150–220ms |
| 再进入 merge timeline | 落稳完成后或并行短重叠 ≤50ms |

### 5.4 验收句

1. 投影偏空 → 绿/可放，松手搬家。  
2. 投影同数且 T* 合法 → 蓝+外形+方向，松手=该 T*。  
3. 不同数 → 红，松手弹回。  
4. 跟手偏左可合 → 向左长（单侧）。  
5. U6 槽 → 左右各 +1，预览已显示 4×2。  
6. 意图侧非法 → 不可合，不静默改向。  
7. F7：偏置在跟手上可见。

## 10. 补漏循环结论（三轮）

### 10.1 循环 1 — 阈值 · aim · 多目标 · 槽算法

| 项 | 冻结建议 |
|----|----------|
| 同数可合 | 投影脚印与 B **≥1 格重叠**（不要边邻-only） |
| aim | `aim = finger − (0, offsetY)`；F 与 G 同源 |
| 多目标 | 重叠格数最大 → 并列 G 中心距最近 |
| 槽搜索 | 对 `Shapes(2V)` × 盘面 top-left 枚举；8×8 足够快，不必复杂 MER |

### 10.2 循环 2 — 朝向 · θ · 预告范围 · perf

| 项 | 冻结建议 |
|----|----------|
| 顺序 | **canMergeByShape 最先**；否 → blocked |
| ε / 单侧 | ε≈**0.3 格**；protrusion≥0.5 或 exclusive≥1 → 高置信 |
| T* 预告 | 只预告 **合后锚点外形**；不预告每条推迹 |
| 原位 | 逻辑腾空；可选半透明残影 |
| 每帧预算 | 逻辑 **&lt;2ms**；禁止每帧 full tryMerge |

### 10.3 循环 3 — 软吸附 · 并列 · 边界

| 项 | 冻结建议 |
|----|----------|
| 软吸附 | **默认关闭**（投影即结果） |
| 双侧 vs 单侧 | 槽 bilateral 分 ≥ 单侧 + **0.5 格等价 margin** → 双侧 |
| 出界 | 盘外/letterbox：保持最后态或 blocked，松手弹回 |
| animating | 禁止 lift |
| a11y / 完整 haptics 曲 | **后置** |

### 10.4 更新：采纳 / 拒绝

| 项 | 决定 |
|----|------|
| 边邻即合 | **拒绝**（要重叠≥1） |
| 软吸附默认开 | **拒绝** |
| 朝向不合仍算几何 | **拒绝**（先朝向） |
| 每帧 tryMerge | **拒绝** |
| 8×8 枚举槽 | **采纳** |
| 重叠选目标 | **采纳** |
